# xbdz-0378 兴邦厨卫湿度控制器

本项目为**青岛兴邦厨卫排气扇自动湿度控制器**固件工程。

- **电路板专用号**：0060900378
- **总成号**：1060801044
- **主控 MCU**：赛元微电子 (SinOne) `SC92F7251M16U` (SOP-16, 1T 8051内核, 12MHz, 4KB Flash, 256B RAM)
- **编译工具**：Keil C51 (v9.60+)

---

## 功能特性

1. **双旋钮硬件调节**：
   - **W1 (P1.6 / AIN9)**：排风延时时间可调，范围 **5 ~ 60 min**，顺时针增大。
   - **W2 (P1.7 / AIN8)**：湿度触发阈值可调，范围 **30% ~ 80% RH**，顺时针增大。

2. **双重智能排气触发机制**：
   - **阈值触发**：环境实测相对湿度 $\ge$ 设定阈值时，继电器立即吸合启动风机；
   - **动态急剧上升触发**：当检测到湿度在基准上首次上涨超过 5% 时开启 3 分钟计时；若 3 分钟内再次上涨超过 5%（洗澡/蒸汽剧烈上升），智能提前启动风机排湿；
   - **风机运行续命**：排风运行期间若再次检测到持续上升，重新完整延时计时。

3. **HS-313 湿敏传感器精准采集与温度补偿**：
   - **1kHz 交流激励防极化**：利用 Timer2 产生 1kHz 交流方波驱动 HS-313，消除直流极化；
   - **正半周期平顶同步采样**：在正半周平稳段进行峰值 ADC 采集并平均滤波；
   - **低湿容抗基底补偿**：针对 HS-313 在低湿（<35% RH）下的极间固有容抗旁路效应，引入基底偏置校准，确保 20%~80% RH 全量程线性精准吻合；
   - **板载 NTC 动态温补**：实时采集板载 10K (B3950) NTC 温度，动态切换 8 档温度校准曲线（5℃~40℃），并带 NTC 异常开短路安全保护。

4. **单线串口调试与 4 位数码管测试通讯**：
   - 支持通过 DIO (P1.3) 输出 `0xAA 0x55 [实测湿度/延时] [设定阈值]` 供产线测试板实时显示。

## 固件编译指南

1. 打开 Keil uVision，通过 `Project -> Open Project` 载入 `0378_Humidity_Controller.uvproj`；
2. 点击 `Build` (F7) 进行全工程编译；
3. 编译成功后输出 Intel HEX 文件至 `Objects/0378_Humidity_Controller.hex`，使用赛元 SOC Programmer 烧录进芯片即可。
